# Hands-On Practice Materials

**Purpose**: In-class practice activities for learning and experimentation

## What is This Folder?

This folder contains hands-on practice activities that you'll work through **during class time** or **at home** for extra practice. These are different from your take-home assignments - they're designed for practice and experimentation. **They are not required and not graded.**

## How to Access Materials

**All practice materials are available in the course template repository:**

👉 **<https://github.com/bds134/hist501d-coursework-template/tree/main/hands-on>**

You have two options for accessing these materials:

### Option 1: Browse Online (Easiest)
- Click the link above to view all practice files on GitHub
- Read through activities directly in your browser
- Copy code snippets as needed

### Option 2: Copy to Your Repository (Recommended for active practice)
- Navigate to the course template repository: <https://github.com/bds134/hist501d-coursework-template>
- Download or copy the files you want to work on
- Add them to a `hands-on/` folder in your personal coursework repository
- Work on them in VS Code

**Note**: You can add practice files to your main branch or create a separate `hands-on` branch - your choice!

## Practice Files by Week

- **Week 1**: VSCode, Command Line, Markdown, Git Basics
- **Week 2**: Python Fundamentals
- **Week 3-9**: Additional topics (added weekly)

Check the GitHub repository for new materials as we progress through the course.

## How to Use

1. **During class**: Open the practice file for the current week and work through the activities
2. **Follow along**: Instructor will guide you through some exercises
3. **Work at your pace**: You don't need to finish everything - practice what you can
4. **Commit your work** (optional): You can commit practice work or leave it uncommitted - either is fine
5. **Don't stress**: These are learning exercises, not graded assignments

## Tips

- Practice work is **optional** - you don't need to commit or submit practice exercises
- **Experiment freely**: This folder is for learning - mistakes are encouraged!
- **Reference later**: Come back to these exercises when working on assignments
- Keep files organized by week in your `hands-on/` folder
