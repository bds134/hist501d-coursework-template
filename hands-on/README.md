# Hands-On Practice Materials

**Purpose**: In-class practice activities

## What is This Folder?

This folder is for hands-on practice activities that you'll work through **during class time** or **at home** for extra practice or to continue working on the in-class demo. These are different from your take-home assignments - they're designed for practice and experimentation; they are not required nor graded.

## How to Access Materials

1. **Download from Brightspace**: Each week, practice files will be posted in the "Hands-On" content module on Brightspace
2. **Create this folder** (if it doesn't exist): In your coursework repository, create a `hands-on` folder
3. **Add downloaded files**: Save the downloaded practice files into your `hands-on` folder
4. **Work on activities**: Open the files in VS Code and complete the practice exercises

**Note**: You can add this folder to your main branch or create a separate `hands-on` branch - your choice!

## Practice Files by Week

Each week, new practice files will be available on Brightspace:

- **Week 1**: VSCode, Command Line, Markdown, Git Basics
- **Week 2**: Python Fundamentals
- **Week 3-9**: Additional topics (files posted weekly)

Download the files from Brightspace and add them to this folder as we progress through the course.

## How to Use

1. **During class**: Open the practice file for the current week and work through the activities
2. **Follow along**: Instructor will guide you through some exercises
3. **Work at your pace**: You don't need to finish everything - practice what you can
4. **Commit your work** (optional): You can commit practice work or leave it uncommitted - either is fine
5. **Don't stress**: These are learning exercises, not graded assignments

## Optional: Using Git Branches for Practice

**Want to keep practice work separate?** You can create a separate branch for hands-on work. This is **recommended but not required** - it's completely fine to work directly in your main branch.

**Why use a branch?**

- Keeps your graded work separate and organized
- Allows you to experiment without affecting assignments
- You can delete practice work easily if you want

**How to create and use a practice branch:**

```bash
# Create and switch to a new branch
git checkout -b hands-on

# Work on practice exercises
# ... do your work ...

# Commit your practice work
git add .
git commit -m "Completed Week 2 practice"
git push -u origin hands-on

# Switch back to main for assignments
git checkout main
```

**But remember**: It's perfectly fine to skip branches and just work in your main branch. Your choice!
